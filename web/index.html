导入数据源（糖葫芦 / CatPawOpen 风格）

粘贴单个 .js 源码，或填写可直链下载的 URL。脚本需含 spider 对象与 id/name 元信息，接口约定与糖葫芦一致（home / category / detail / search / play）。

数据源管理

内置源随镜像发布，不可删除；导入的 JS 源存放在数据卷 /app/data/sources 里，重建容器不丢。内置源和 URL 导入源会自动检查上游更新，更新失败会保留旧版本。

观看历史

保存在本浏览器（localStorage），不上传服务器。点条目即可从上次的位置续播。

登录

账号数据（观看历史、收藏、追剧）保存在服务端 SQLite，多设备登录后自动同步。

我的收藏

收藏保存在服务端，换设备登录后依然在。

追剧提醒

追更的剧集有新集时会在这里提示（打开页面和每隔 10 分钟自动检查）。
